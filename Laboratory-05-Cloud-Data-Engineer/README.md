# Laboratory 05 - The Cloud Data Engineer

## Mission Overview

This laboratory activity focused on cloud object storage using MinIO. The goal was to deploy an S3-compatible storage server using Docker, access its web console, create a storage bucket, and upload a test object.

## Objectives

- Understand the differences between Block, File, and Object Storage.
- Deploy MinIO using Docker.
- Configure Docker environment variables.
- Access the MinIO Web Console through port forwarding.
- Create an object storage bucket.
- Upload an object to the bucket.
- Document the deployment using Markdown.
- Maintain the Cloud Computing GitHub portfolio.

## Tools Used

- KillerCoda Playground
- Ubuntu
- Docker
- MinIO
- GitHub
- Markdown
- Web Browser

## Skills Learned

- Linux command-line operations
- Docker container deployment
- Environment variable configuration
- Object storage concepts
- MinIO administration
- Bucket creation and object uploading
- Technical documentation using Markdown
- GitHub repository management
