# Laboratory 05 - The Cloud Data Engineer

## Mission Overview

This laboratory activity focused on cloud object storage using MinIO. The main task was to deploy an S3-compatible object storage server with Docker in the KillerCoda Ubuntu Playground. After deploying MinIO, the web console was accessed through port 9001, a storage bucket was created, and a test file was uploaded to verify that the storage system was working.

## Objectives

- Understand the differences between Block, File, and Object Storage.
- Deploy an S3-compatible MinIO server using Docker.
- Configure MinIO using Docker environment variables.
- Access the MinIO Web Console through port forwarding.
- Create a storage bucket named `client-photos`.
- Upload a test object to the bucket.
- Document the deployment process using Markdown.
- Organize and maintain the Cloud Computing GitHub portfolio.

## Tools Used

- KillerCoda Playground
- Ubuntu 24.04
- Docker
- MinIO
- GitHub
- Markdown
- Web Browser

## Skills Learned

- Linux command-line operations
- Docker container deployment
- Docker port mapping
- Environment variable configuration
- Object storage concepts
- MinIO administration
- Bucket creation and object uploading
- Technical documentation using Markdown
- GitHub repository management

## Mission Result

The MinIO object storage server was successfully deployed using Docker. The MinIO Web Console was accessed through port `9001`, and the `client-photos` bucket was created. A test file was uploaded to the bucket to confirm that the object storage environment was functioning correctly.
