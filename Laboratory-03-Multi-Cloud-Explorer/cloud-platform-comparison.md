## 2. Comparison Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest selections of cloud services among the three major providers. It provides services for computing, storage, databases, networking, security, analytics, artificial intelligence, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. It works closely with products such as Windows Server, Microsoft 365, and Microsoft Entra ID, making it a suitable choice for organizations that already use Microsoft's ecosystem.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud Platform is a strong choice for Artificial Intelligence, Machine Learning, and Kubernetes. Google Cloud provides AI and data services as well as Google Kubernetes Engine (GKE), which is a managed Kubernetes service.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a wide range of cloud services and can support different types of applications and organizations. I also think AWS is a good platform for learning because it provides many services that can help me understand different areas of cloud computing.

## 4. Observation

After comparing AWS, Azure, and GCP, I observed that all three platforms provide similar basic cloud services such as virtual machines, storage, databases, networking, and identity management. However, each provider has different strengths. AWS stands out for its broad range of services, Azure is strong in Microsoft integration, while GCP is particularly strong in artificial intelligence, data analytics, and Kubernetes. This comparison helped me understand that choosing a cloud provider depends on the specific needs of an organization rather than simply choosing the most popular platform.
