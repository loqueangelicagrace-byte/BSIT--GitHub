## Reflection

The cloud platform that impressed me the most is Amazon Web Services (AWS). I was impressed by the wide range of services that AWS provides for computing, storage, databases, networking, security, and other cloud requirements. I also learned that AWS can support different types of organizations, from startups to large enterprises.

AWS, Microsoft Azure, and Google Cloud Platform have many similarities. All three platforms provide important cloud services such as virtual machines, object storage, databases, networking, and identity management. They also provide scalable infrastructure that allows organizations to increase or decrease resources depending on their needs. However, each platform has different strengths, such as AWS having a broad range of services, Azure having strong Microsoft integration, and GCP being strong in artificial intelligence, data analytics, and Kubernetes.

Business requirements have an important influence on cloud platform selection. Organizations need to consider their budget, existing technologies, workload, security requirements, performance, scalability, and business goals. For example, Azure is a good choice for an organization that already uses Microsoft technologies, while GCP can be suitable for companies focused on artificial intelligence and machine learning.

Acting as a Cloud Solutions Consultant helped me understand that choosing a cloud provider is not simply about selecting the most popular platform. The provider should be selected based on the specific needs and requirements of the client. I learned how to compare cloud services and match them with different business scenarios.

My GitHub Cloud Computing Portfolio also improved after completing this mission. I added organized research files, comparison tables, recommendations, and documentation about AWS, Azure, and GCP. This helped me practice documenting technical information using Markdown and organizing my cloud computing work professionally.
