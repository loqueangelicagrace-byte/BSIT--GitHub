# Client Recommendations

## 1. Client A – Startup Company

### Recommended Platform: AWS

AWS is a good choice for the startup because it provides many cloud services that can support a new mobile application. The startup has a limited budget, so it can begin with the resources it needs and increase them as the application grows. AWS also provides scalable services that can support increasing numbers of users. This makes AWS suitable for a startup that expects rapid growth.

**Recommended Services:**

* Amazon EC2 – for running application servers
* Amazon S3 – for storing files and application data
* Amazon RDS – for managing the application's relational database

---

## 2. Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the most appropriate choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure has strong integration with Microsoft's existing technologies, which can make the migration process easier. The university can move selected services to Azure while continuing to use its existing Microsoft environment. Azure can also support hybrid cloud environments.

**Recommended Services:**

* Azure Virtual Machines – for running Windows Server workloads
* Microsoft Entra ID – for identity and access management
* Azure SQL Database – for hosting relational databases

---

## 3. Client C – AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

Google Cloud Platform is a suitable choice for the AI research company because it provides strong services for artificial intelligence and machine learning. The company requires high-performance computing, so it can use Google Cloud computing resources designed for demanding workloads. GCP also provides tools for data processing and machine learning development. Its Kubernetes service can also support modern AI applications that use containers.

**Recommended Services:**

* Google Compute Engine – for high-performance computing workloads
* Vertex AI – for developing and deploying AI and machine learning applications
* Google Kubernetes Engine (GKE) – for deploying containerized applications

---

## 4. Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is a suitable choice for the global e-commerce company because it provides a large global infrastructure that can support applications used by customers around the world. The company requires highly available infrastructure and automatic scaling, and AWS provides services that can help meet these requirements. AWS can distribute workloads across different Availability Zones and regions to improve availability. Its scalable services can also help the company handle changes in customer traffic.

**Recommended Services:**

* Amazon EC2 – for running web and application servers
* Amazon S3 – for storing product images, files, and other data
* Elastic Load Balancing – for distributing application traffic
* Amazon EC2 Auto Scaling – for automatically adjusting computing capacity

---

# 5. Multi-Cloud Decision Matrix

| Business Requirement        | Recommended Platform | Justification                                                                                                                                          |
| --------------------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Startup Company**         | AWS                  | AWS provides scalable cloud services that allow startups to begin with the resources they need and expand as their applications grow.                  |
| **Enterprise Organization** | AWS                  | AWS provides a broad range of services and global infrastructure that can support complex enterprise workloads.                                        |
| **Microsoft Environment**   | Microsoft Azure      | Azure integrates strongly with Microsoft technologies such as Windows Server, Microsoft 365, and Microsoft Entra ID.                                   |
| **AI / Machine Learning**   | GCP                  | GCP provides strong artificial intelligence and machine learning services suitable for AI-focused organizations.                                       |
| **Kubernetes Deployment**   | GCP                  | Google Kubernetes Engine (GKE) provides a managed Kubernetes environment for deploying and managing containerized applications.                        |
| **Global Web Application**  | AWS                  | AWS provides global infrastructure, scalable computing, storage, and networking services that can support applications serving users around the world. |

## 6. Observation

After analyzing the four client scenarios, I observed that there is no single cloud platform that is always the best choice for every organization. The best provider depends on the company's budget, existing technology, workload, and business requirements. AWS is a strong choice for startups and global applications, Azure is especially suitable for organizations using Microsoft technologies, and GCP is a strong option for artificial intelligence and Kubernetes workloads. This activity helped me understand why cloud platform selection should be based on the specific needs of the client.
