## Guide Questions & Answers

### 1. Which cloud provider offers the broadest range of services? Explain your answer.
Amazon Web Services (AWS) offers the broadest range of services due to its pioneer status and vast market presence. It features an extensive catalog of specialized cloud products spanning compute, database technologies, internet of things (IoT), and edge computing solutions.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
Microsoft Azure is recommended because it offers native integration with Active Directory, Windows Server, Office 365, and SQL Server environments. This allows seamless identity management, migration paths, and licensing benefits via Microsoft Entra ID and hybrid cloud options.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
Google Cloud Platform (GCP) is widely recognized for AI, ML, and Kubernetes services. As the original creator of Kubernetes, GCP provides Google Kubernetes Engine (GKE) alongside advanced AI framework platforms like Vertex AI.

### 4. What similarities did you observe among the three cloud providers?
All three providers share identical core foundational primitives, offering scalable virtual machines, object storage buckets, isolated virtual networks, and granular identity access controls. Additionally, each platform utilizes a pay-as-you-go pricing model accompanied by robust management interfaces and CLI support.
