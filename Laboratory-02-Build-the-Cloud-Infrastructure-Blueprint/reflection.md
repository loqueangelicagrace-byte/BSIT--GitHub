
# Mission 2 Reflection

Of all the cloud infrastructure components, I consider networking to be the most critical. While compute and storage are essential for processing and retaining data, networking provides the foundation that connects these resources to each other and to end users. Without a secure and well-architected network topology, cloud services cannot process external requests, communicate with database layers, or enforce security perimeters.

Linux plays a fundamental role in cloud computing as the industry-standard operating system powering the vast majority of cloud instances, containers, and hypervisors. Its open-source nature, resource efficiency, scriptability, and robust CLI capabilities make it ideal for automated deployments and infrastructure management across modern public clouds.

Comprehensive technical documentation prior to infrastructure deployment is vital because it acts as an architectural blueprint. It prevents design flaws, mitigates security misconfigurations, establishes cost expectations, and ensures seamless knowledge transfer among team members. Documenting decisions beforehand guarantees that systems are built deliberately rather than reactively.

Through this laboratory activity, I gained practical skills in inspecting system resources using Linux commands, analyzing cloud provider equivalents across AWS, Azure, and GCP, and mapping out network architectures. Furthermore, I improved my technical writing capabilities by using Markdown to document engineering findings cleanly.

Completing this mission has significantly enhanced my GitHub Cloud Computing Portfolio. Adding structured reports, markdown documentation, and architectural diagrams transforms the repository from a simple file storage location into a professional engineering portfolio that demonstrates applied technical proficiency.
